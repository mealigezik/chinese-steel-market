# Chinese Steel Market - HTML Prototypes

This repository contains standalone HTML prototypes for steel product information and tabular layouts.

## Files
- `sac-metal.html` - product navigation links and category layout.
- `tablo.html` and `tablo2.html` - static table/layout experiments.
- `deneme.html` - steel plate specification text.

## Important
Keep customer documents, medical records, personal data, credentials, and non-public business information out of this public repository. Verify ownership and redistribution rights for all product data and page assets before reuse.

## Status
Static HTML/CSS prototype; no backend, automated tests, or live inventory integration.
